Test jezelf

  1. Welk apparaat is verantwoordelijk voor het opstarten van een computer?
    • De TPM chip
    • De BIOS / UEFI
    • De harde schijf
    • De MBR
  2. Waarvoor staat de afkorting BIOS?
     
    Basic Input Output System.
  3. Hoe worden de instellingen van de BIOS / UEFI behouden, zelfs als de computer uit staat?
    • De instellingen gaan verloren als de computer uit staat
    • De instellingen worden gekopieerd naar de harde schijf
    • De instellingen worden gekopieerd naar het RAM geheugen
    • Door een batterij op het moederbord
  4. Wat is het doel van de POST bij het starten van een computer?
    • Om het besturingssysteem te laden
    • Informatie bijhouden over het bestandssysteem
    • Om de hardware van de computer te controleren op aanwezigheid en goede werking
    • Om te controleren als e-mails kunnen worden verstuurd
  5. Hoe zou je de MBR het best omschrijven?
    • Een procedure die de computer doorloopt om te controleren als alle hardware aanwezig is en werkt
    • Een kleine ruimte op de harde schijf waar instructies staan om de computer verder op te starten
    • Een systeem dat voorkomt dat malware kan gestart worden zodra je computer is opgestart
    • Geen van deze is correct
  6. Welke van deze is GEEN nadeel van de BIOS ten opzichte van UEFI?
    • De geheugencapaciteit is beperkt (1 MB)
    • Geen beveiliging tegen virussen en malware
    • Traag
    • Ondersteunt enkel harde schijven tot 2TB
    • Limiteert de kloksnelheid van de processor
  7. In welke situaties zou je de BIOS / UEFI instellingen moeten wijzigen?
     
     
     
     
    Om de virtualisatie mogelijkheden aan of uit te zetten, om de processor en het RAM te overklokken, om hardwarefouten vast te stellen, en om de opstartvolgorde aan te passen.
  8. Hoe raak je in de BIOS / UEFI omgeving?
    • Via het configuratiescherm van Windows
    • Door het indrukken van F1, F2, DEL, ... bij het opstarten
    • Via de UART poort op het moederbord
    • Door de AAN knop te blijven indrukken na het opstarten
  9. Hoe maakt de POST hardwarefouten kenbaar?
     
     
    Met een reeks pieptonen, en met een foutboodschap op het scherm zodra er beeld is. Bij een ernstige fout is er nog geen beeld, en dan blijven de pieptonen over.
