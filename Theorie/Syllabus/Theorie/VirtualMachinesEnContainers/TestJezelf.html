Test jezelf

  1. Wikipedia omschrijft een virtuele machine als...
    • een fysieke computer die de werking van een programma nabootst.
    • een computerprogramma dat andere programma's van elkaar volledig gaat afscheiden.
    • een computerprogramma dat de werking van een echte, fysieke computer nabootst.
  2. Als jouw computer één of meerdere virtuele machines draait dan is jouw computer...
    • Het host systeem
    • Het guest systeem
  3. Welke bewering is NIET WAAR wat betreft virtuele machines?
    • Virtualiseren is kostenbesparend
    • Virtuele systemen zijn compleet gescheiden van elkaar
    • Een virtuele machine is trager dan een fysieke machine
    • Als er hardware (CPU / RAM / HD) crasht blijft de virtuele machine gewoon verder werken
  4. Wat maakt van een computer een server?
    • Dat hij in een 19" rack past en 1U hoog is.
    • Dat hij een dienst levert aan andere machines of gebruikers in het netwerk.
    • Dat hij een krachtige processor, veel werkgeheugen en een snelle schijf heeft.
    • Dat er geen scherm en geen toetsenbord op aangesloten zijn.
  5. Waarom is een virtuele machine trager dan dezelfde hardware zonder virtualisatie?
    • Omdat de host elke instructie van de guest eerst vertaalt voor de processor ze uitvoert.
    • Omdat elke guest een eigen besturingssysteem draait dat zelf processortijd en werkgeheugen vraagt, en omdat de nagebootste randapparaten langs de host lopen.
    • Omdat een virtuele harde schijf altijd trager is dan een fysieke schijf.
    • Omdat de processor op een lagere kloksnelheid gaat werken zodra er guests draaien.
  6. Je wil op een machine met een x64 processor een besturingssysteem voor ARM draaien. Wat heb je nodig?
    • Niets bijzonders, een virtuele machine draait elk besturingssysteem.
    • Emulatie, want een virtuele machine draait alleen een besturingssysteem met dezelfde instructieset als de processor eronder.
    • Een container, want die deelt het besturingssysteem van de machine.
    • Een tweede licentie voor het guest besturingssysteem.
  7. Wat is het voordeel van een container ten opzichte van een virtuele machine?
    • Een container schermt programma's beter van elkaar af.
    • Het besturingssysteem wordt niet telkens mee gevirtualiseerd, waardoor de overhead en de extra licentie wegvallen.
    • Een container heeft geen processortijd nodig van de machine waarop hij staat.
    • Een container kan op hardware draaien zonder besturingssysteem eronder.
  8. Wat kan een virtuele machine wel en een container niet?
    • Meerdere programma's tegelijk draaien.
    • Een ander besturingssysteem draaien dan dat van de machine eronder.
    • Programma's van elkaar afschermen.
    • Op zowel Windows als Linux geïnstalleerd worden.
