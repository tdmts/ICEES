Test jezelf

  1. Het principe van de Von Neumann architectuur is dat ...
    • Een computer voldoende werkgeheugen moet hebben om alle instructies en data te bevatten die uitgevoerd moeten worden door de processor
    • Een computer maar zo snel kan werken als het traagste component (de bottleneck)
    • Data en instructies in het werkgeheugen (RAM) moeten staan om uitgevoerd te kunnen worden
  2. Teken het schema van de Von Neumann architectuur. Maak het concreet door bij ieder blok minstens één hardware component op te noemen dat je kan terugvinden in een moderne computer.
     
    Het schema van 5.1, met bij elk blok een onderdeel uit een moderne computer: invoer is een toetsenbord of een muis, uitvoer is een scherm of een printer, de centrale verwerkingseenheid is de processor, het geheugen is een RAM-module, de opslag is een SSD of een harde schijf, en de systeembus zijn de banen op het moederbord tussen de processor en het geheugen.
  3. Als een computer traag opstart maar daarna vrij vlot werkt dan is de bottleneck waarschijnlijk ...
    • De harde schijf
    • Het werkgeheugen
    • De processor
  4. Een x64 Core 7 processor heeft als eigenschappen ...
    • Focus op een snelle en efficiënte communicatie van de kernen met het RAM geheugen
    • Focus op performantie (hoge kloksnelheid, veel kernen, ...) maar weinig energiezuinig
    • Focus op ze weinig mogelijk communicatie met het RAM geheugen
  5. De programma's geschreven voor een ARM instructieset zijn compatibel met die geschreven voor een x64 instructieset
    • Ja, alle software draait op allebei de instructiesets
    • Ja, zolang aan allebei de kanten hetzelfde besturingssysteem draait
    • Ja, want elke ARM processor voert x64 instructies ook uit, alleen trager
    • Nee, een programma voor ARM draait niet op x64 en moet daarvoor opnieuw geschreven worden
