Je systeem up to date houden

Je hebt op zes pagina's zeven programma's geïnstalleerd, langs vijf verschillende wegen. Op deze pagina werk je je machine bij, en je kijkt na welk van die zeven daarin meegaat.

Met de Software Updater

  1. Klik op Activities, typ software en kies Software Updater. Dat is het pictogram met de ronde pijl, en niet Software & Updates dat je op de Spotify-pagina gebruikt hebt.

  2. Het programma kijkt eerst wat er te vernieuwen is en toont daarna een lijst. Klik op Install Now en geef je wachtwoord.

Met apt

Hetzelfde in de terminal, met twee commando's die je alle twee al gezien hebt.

  1. Haal eerst de lijst op van wat er in de repositories staat. Dit installeert nog niets.

    elm@elm-VirtualBox:~$ sudo apt update 
    Hit:1 http://be.archive.ubuntu.com/ubuntu focal InRelease
Hit:2 http://security.ubuntu.com/ubuntu focal-security InRelease
Get:3 http://repository.spotify.com stable InRelease [3.499 B]
Reading package lists... Done
Building dependency tree
Reading state information... Done
14 packages can be upgraded. Run 'apt list --upgradable' to see them.

    In de eerste regels staan de repositories die je machine kent, en die van Spotify staat erbij omdat je ze zelf toegevoegd hebt.

  2. Installeer daarna van elk pakket de nieuwere versie.

    elm@elm-VirtualBox:~$ sudo apt upgrade

Wat er meegaat en wat niet

Kijk de lijst na die apt upgrade je toont, en leg ze naast wat je geïnstalleerd hebt.

De zeven programma's van dit labo, en wat er met hun updates gebeurt

De twee laatste staan in geen enkele lijst van je machine, dus komt er een nieuwe versie uit, dan gaat dat aan je voorbij tenzij je zelf gaat kijken. Bij een programma dat aan het internet hangt, is dat het argument om zo lang mogelijk bij de eerste wegen te blijven.

Snaps werken zichzelf bij

Een snap staat los van apt en heeft zijn eigen mechanisme, dat een paar keer per dag kijkt of er iets nieuws is. Je hoeft er dus niets voor te doen, en je ziet VLC daarom ook niet in de lijst van apt upgrade staan. Wil je het toch met de hand doen, dan is dat sudo snap refresh.
