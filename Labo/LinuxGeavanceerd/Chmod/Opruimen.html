Een gebruiker en een lidmaatschap wissen

De gebruiker labopartner3 was er alleen om te tonen dat sudo werkt, en die mag weg. Daarna haal je labopartner2 uit de groep sudo, zonder hem te wissen. Eén commando doet die twee dingen: deluser.

Wat deluser allemaal kan

  1. Vraag het commando zelf. Bijna elk Linux-commando toont met --help zijn opties.

    elm@elm-VirtualBox:~$ deluser --help 
    deluser USER
  remove a normal user from the system
  example: deluser mike

  --remove-home             remove the users home directory and mail spool
  --remove-all-files        remove all files owned by user

deluser USER GROUP
  remove the user from GROUP

De gebruiker wissen

Zonder opties haalt deluser de gebruiker weg en laat het zijn map onder /home staan, met alles wat erin zit. Dat is met opzet: het systeem gooit niet ongevraagd bestanden weg waar nog werk in kan zitten.

2. Wis labopartner3 samen met zijn map /home/labopartner3.

Toon antwoord
elm@elm-VirtualBox:~$ sudo deluser --remove-home labopartner3 
[sudo] password for elm:
Looking for files to backup/remove ...
Removing files ...
Removing user `labopartner3' ...
Warning: group `labopartner3' has no more members.
Done.

De waarschuwing onderaan gaat over de groep die bij het aanmaken vanzelf meekwam: die blijft nu leeg achter.

Een gebruiker uit een groep halen

Zet je een groepsnaam achter de gebruikersnaam, dan wist deluser niets: het haalt alleen het lidmaatschap weg.

3. Haal labopartner2 uit de groep sudo.

Toon antwoord
elm@elm-VirtualBox:~$ sudo deluser labopartner2 sudo 
Removing user `labopartner2' from group `sudo' ...
Done.

4. Kijk na wie er nu nog in de groep sudo zit.

Toon antwoord
elm@elm-VirtualBox:~$ members sudo 
elm labopartner1

labopartner2 bestaat nog gewoon en kan zich nog aanmelden. Wat hij kwijt is, is het recht om sudo te gebruiken.

Je bent klaar voor de opdracht

Je kan nu gebruikers en groepen maken, wisselen met su, iemand sudo geven en het weer afnemen. Op de volgende pagina staat het document dat je invult en indient: daarin maak je twee nieuwe gebruikers en zet je de rechten van een bestand.
