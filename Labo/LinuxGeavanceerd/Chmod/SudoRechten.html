Een gebruiker sudo-rechten geven

Je twee nieuwe gebruikers bestaan, maar ze mogen nog niets aan het systeem veranderen. Op deze pagina geef je ze dat recht, en je kijkt daarna na wie het op deze machine heeft.

Wat er gebeurt zonder dat recht

1. Meld je aan als labopartner1.

Toon antwoord
elm@elm-VirtualBox:~$ su labopartner1

  1. Probeer als labopartner1 een derde gebruiker aan te maken.

    labopartner1@elm-VirtualBox:/home/elm$ sudo adduser labopartner3 
    [sudo] password for labopartner1:
labopartner1 is not in the sudoers file.  This incident will be reported.

    Het wachtwoord klopte, dus opnieuw proberen helpt niet. Wat ontbreekt is het recht om sudo te gebruiken, en dat hangt aan een groep die op Ubuntu ook sudo heet.

De gebruikers in de groep sudo zetten

Iemand die dat recht al heeft, moet het geven. Dat is de gebruiker die je bij de installatie van Ubuntu gemaakt hebt.

  1. Keer eerst terug naar die gebruiker.

    labopartner1@elm-VirtualBox:/home/elm$ exit

  2. Zet allebei de gebruikers in de groep sudo. De G staat voor de groepen waar hij bij komt, en de a voor append.

    elm@elm-VirtualBox:~$ sudo usermod -aG sudo labopartner1
    elm@elm-VirtualBox:~$ sudo usermod -aG sudo labopartner2
    De a is niet optioneel

    Laat je hem weg, dan vervangt usermod alle groepen van die gebruiker door de ene die je opgeeft, en verliest hij zijn eigen groep.

5. Meld je opnieuw aan als labopartner1 en maak nu wel de gebruiker labopartner3 aan.

Toon antwoord
elm@elm-VirtualBox:~$ su labopartner1
labopartner1@elm-VirtualBox:/home/elm$ sudo adduser labopartner3 
To run a command as administrator (user "root"), use "sudo <command>".
See "man sudo_root" for details.

[sudo] password for labopartner1:
Adding user `labopartner3' ...
Adding new group `labopartner3' (1003) ...
Adding new user `labopartner3' (1003) with group `labopartner3' ...
Creating home directory `/home/labopartner3' ...
Copying files from `/etc/skel' ...

Vergeet daarna niet met exit terug te keren naar je eigen gebruiker.

Nakijken wie in een groep zit

Het commando members toont de gebruikers van een groep, maar het staat niet standaard op Ubuntu.

  1. Probeer het toch eens, en lees wat de terminal zegt.

    elm@elm-VirtualBox:~$ members sudo 
    Command 'members' not found, but can be installed with:

sudo apt install members

    De terminal zegt zelf welk pakket je nodig hebt en met welk commando je het haalt.

  2. Doe wat er staat.

    elm@elm-VirtualBox:~$ sudo apt install members

  3. Probeer nu opnieuw.

    elm@elm-VirtualBox:~$ members sudo 
    elm labopartner1 labopartner2

    Drie gebruikers mogen op deze machine sudo gebruiken. labopartner3 staat er niet bij: die is door labopartner1 gemaakt, en dat geeft hem geen rechten.
