De commando's

De achttien commando's van dit labo
Commando Waar het voor staat Wat het doet De opties die je hier gebruikt
pwd print working directory Toont het volledige pad van de map waar je staat
ls list Toont wat er in een map staat -l per regel met alle gegevens
-a ook de verborgen namen
-h groottes in K, M en G
-t gesorteerd op tijd
-alh de drie eerste samen
cd change directory Verandert de map waar je staat cd ~ naar je eigen map
cd .. één niveau hoger
cd /etc naar een absoluut pad
clear Maakt het venster leeg. Je geschiedenis blijft staan
history Toont de commando's die je ingegeven hebt, genummerd
mkdir make directory Maakt een map aan
nano Opent een bestand in een eenvoudige teksteditor, en maakt het aan als het nog niet bestaat
vi Doet hetzelfde, en staat op elke machine waar nano ontbreekt
cp copy Kopieert een bestand of een map naar een tweede plaats -r voor een map en alles eronder
* voor alle bestanden van een map
mv move Verplaatst of hernoemt. Binnen dezelfde map is het een hernoeming, naar een ander pad een verplaatsing
rm remove Wist een bestand. Er is geen prullenbak -r voor een map en alles eronder
du disk usage Toont hoeveel schijfruimte een map inneemt -s ofwel --summarize, één totaal in plaats van een regel per map
-h in K, M en G
sudo super user do Voert het commando erachter uit als root. Vraagt je eigen wachtwoord
find Zoekt bestanden vanaf een startmap en in alles eronder -name op bestandsnaam
-amin op wanneer het bestand voor het laatst gelezen is
ps process status Toont de processen zoals ze draaien op het moment dat je het intypt -e alle processen van de machine in plaats van alleen die van jou
more Toont lange uitvoer een scherm per keer
| pipe Geeft de uitvoer van het linkse commando door als invoer van het rechtse
tar tape archive Bundelt mappen en bestanden tot één archiefbestand, en pakt het weer uit -cvzf maken en comprimeren
-xvzf uitpakken
-tvzf de inhoud tonen zonder uit te pakken
shutdown Zet de machine uit of start ze opnieuw op. Vraagt sudo -h now nu uitzetten
-r now nu heropstarten
-r 5 heropstarten over vijf minuten
reboot Kortere schrijfwijze van shutdown -r now. Vraagt sudo
--help Geen commando maar een optie die bij elk commando werkt, en zijn opties opsomt

De mappen

Waar in Linux staat wat in Windows onder C: staat
Windows Linux Wat erin staat
C:\ / Het startpunt van de boom
C:\Users /home De persoonlijke mappen. Die van jou is /home/elm, ofwel ~
C:\Program Files /usr De programma's die erbij geïnstalleerd zijn
C:\Windows /bin en /sbin De hulpprogramma's, voor gebruikers en voor beheerders
/etc De configuratiebestanden
/lib en /lib64 De gedeelde bibliotheken
/boot De opstartbestanden
/dev De hardware, elk stuk als een bestand
/proc Systeeminformatie, zoals het gebruik van de processor en van het werkgeheugen
/mnt Waar bijkomende bestandssystemen aangekoppeld worden
/tmp Tijdelijke bestanden
/var Gegevens die tijdens het draaien groeien, waaronder de logbestanden
